# YaCoEducation

Локальная платформа интерактивного обучения: **7 мастерских, 133 занятия**. Каталог с поиском, фильтрами, прогрессом и общей навигацией. Новые мастерские добавляются через файл реестра.

## Быстрый запуск

Нужен Python 3.10+ и современный браузер. Склонируйте репозиторий и запустите сервер:

```bash
git clone https://github.com/Stront80/YaCoEducotion.git
cd YaCoEducotion
python3 приложение/yacoeducation/serve.py
```

Откройте **http://127.0.0.1:8772/**. Остановка — Ctrl+C. Зависимости устанавливать не нужно: Pyodide и его файлы уже включены. Если порт занят: `python3 приложение/yacoeducation/serve.py --port 8780`. Обычный `python -m http.server` вместо serve.py не подходит для маршрутов общего каталога.

## Мастерские

| Мастерская | Практика |
| --- | --- |
| HTML, CSS и JavaScript | Структура, оформление, DOM и интерактивная страница |
| JavaScript | Функции, массивы, объекты, Promise и async |
| Python | Настоящий Python в браузере, данные и функции |
| Ubuntu | Учебный терминал, файлы и команды |
| Vim | Режимы, движения и редактирование |
| tmux | Сессии, окна и панели |
| VPS | SSH, sudo, firewall, обновления, копии и восстановление |

У каждого курса 18 уроков и итоговая практика. Симуляторы изменяют только виртуальные данные браузера; настоящие SSH/UFW/пакеты на компьютере или сервере не запускаются. JavaScript и Python исполняются в браузере с описанными в курсах ограничениями. Не запускайте чужой недоверенный код и не вводите реальные секреты.

## Добавление мастерских

1. Разместите готовый статический сайт в новой папке внутри `приложение/`.
2. Добавьте его описание и source в [workshops.json](приложение/yacoeducation/workshops.json).
3. Проверьте и обновите каталог:

```bash
python3 приложение/yacoeducation/serve.py --check
```

Полная схема, пример записи, подключение прогресса и ограничения — в [инструкции YaCoEducation](приложение/yacoeducation/README.md). Исходники курсов хранятся отдельно; сохраняйте структуру соседних папок.

## Прогресс

Сохранения находятся в браузере и привязаны к адресу, порту и профилю. Прогресс прежних отдельных запусков на других портах автоматически не переносится. Каталог только читает отметки мастерских; облака, аккаунтов и синхронизации нет. Используйте одну активную вкладку курса.

## Проверки

Из корня клона:

```bash
python3 приложение/yacoeducation/serve.py --check
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s приложение/yacoeducation/tests -p 'test_*.py' -v
node приложение/yacoeducation/tests/core.test.cjs
```

Для Node-тестов нужен Node.js с поддержкой node:test и structuredClone. Для использования сайта Node.js не требуется. [Отчёт интеграции](приложение/yacoeducation/проверки.md): 22 теста, 7/7 мастерских с выполнением задания, сохранение/переходы, проверки расширения реестра, пять ширин и текст 200%. Это не повторное прохождение всех 133 занятий; отдельные тесты курсов находятся в их папках.

Сервер слушает только 127.0.0.1 и предназначен для локальной разработки. Для GitHub Pages добавлены отдельная статическая сборка и workflow; сам Python-сервер на Pages не запускается.

## GitHub Pages

Подготовлен workflow [.github/workflows/pages.yml](.github/workflows/pages.yml).
Он запускает проверки, собирает статический сайт и публикует только `_site`.
После разрешённой отправки изменений выберите **Settings → Pages → Source → GitHub Actions**,
затем запустите **Actions → Publish YaCoEducation to GitHub Pages → Run workflow** для main.
Дальнейшие push в main будут автоматически обновлять сайт.
Ожидаемый адрес: **https://stront80.github.io/YaCoEducotion/**.

Локальная сборка без установки зависимостей:

```bash
python3 приложение/yacoeducation/build_static.py --output _site
python3 -m http.server 8773 --bind 127.0.0.1 --directory _site
```

Откройте http://127.0.0.1:8773/. Для повторной сборки укажите новую или пустую папку:
сборщик не удаляет и не перезаписывает существующий результат.
Подробности и ограничения — в [инструкции](приложение/yacoeducation/README.md#github-pages).
Прогресс с локального адреса автоматически на Pages не переносится.
