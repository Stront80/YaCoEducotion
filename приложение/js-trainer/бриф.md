# JS-мастерская: бриф

Дата: 2026-11-26. Пользователь поручил три роли и подтвердил «да, делайте» предложенный формат.

Отдельный локальный курс для новичков: 18 уроков и итоговый проект, настоящий JavaScript в браузере, редактор, вывод console, подсказки, разбор, проверки и сохранение. Никаких установок и публикации.

Каждый запуск использует новый Worker, остановка terminate и тайм-аут 3 секунды. Ввод в примерах задаётся аргументами функций. Курс языка без DOM: числа/строки/условия/циклы, функции/массивы/объекты, JSON/ошибки/Promise/async. Итог — анализатор расходов. DOM уже представлен в соседней веб-мастерской, здесь не эмулируется.

Готовность: 19 решений и альтернатив принимаются, старт/ошибки отклоняются; прогресс восстанавливается, остановка/тайм-аут освобождают интерфейс. Мобильный и широкий экран, увеличенный текст и доступная клавиатурная навигация проверяются. Учебные проверки не защищены от намеренного обхода. Worker не является средой для запуска чужого вредоносного кода.
