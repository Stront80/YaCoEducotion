# JavaScript-мастерская

Отдельный русскоязычный курс для новичков: 18 уроков и итоговый анализатор расходов. Настоящий JavaScript, редактор, вывод console, подсказки, разбор, проверка и локальные черновики. Внешних библиотек и установки зависимостей нет.

## Запуск

Из корня рабочего пространства:

```bash
python3 -m http.server 8770 --bind 127.0.0.1 --directory приложение/js-trainer
```

Откройте **http://127.0.0.1:8770/**. Остановка сервера — Ctrl+C. Если вы уже в папке js-trainer, опустите `--directory приложение/js-trainer`. При занятом порте выберите другой: сохранения привязаны к адресу и порту. Режим file:// не поддерживается. Сервер раздаёт только эту папку и слушает loopback; системные настройки не меняются.

## Как учиться

1. Выберите урок и прочитайте объяснение, задачу и контракт функции.
2. Допишите код и нажмите «Запустить» для вывода своих console.log.
3. Нажмите «Проверить»: среда выполнит код заново и проверит условия на нескольких входах. Проверки могут дополнительно вызвать вашу функцию; её собственные console.log тоже попадут в вывод.
4. При затруднении раскройте подсказку или разбор. Просмотр решения ничего не исполняет и не завершает урок. Перенос решения и сброс заменяют текущий черновик после подтверждения.
5. Переходите дальше; все уроки доступны сразу. После сброса ранее полученная отметка прохождения остаётся.

На телефоне используйте вкладки «Задание», «Код», «Результат». Стрелки/Home/End переключают их с клавиатуры. Tab/Shift+Tab выводят фокус из редактора. Отступ вводится пробелами; Ctrl+Enter или Command+Enter запускает программу. Длинные строки кода прокручиваются внутри редактора.

## Программа

- Первые строки: console.log, переменные/числа, строки, преобразования типов, условия, циклы.
- Функции и данные: возврат, массивы, map, filter, объекты, reduce и корзина.
- Практика языка: строковые методы, JSON, try/catch, Promise, async/await, валидация.
- Итоговый проект: сводка расходов с фильтрацией, суммой, количеством и категориями, включая специальные имена свойств.

Это курс языка без DOM. В Worker нет document/window/localStorage, prompt/alert и Node.js require. DOM-практика есть в соседней веб-мастерской, но она не является зависимостью этого сайта. Входные данные передавайте аргументами функций и собственными примерами в коде.

## Выполнение и ограничения

На каждый запуск создаётся новый Blob-Worker. Код выполняется в строгой async-функции, поэтому верхнеуровневый await допустим; import/export и глобальная область обычного script не моделируются. Проверки добавляются в ту же лексическую область, чтобы видеть функции и const/let ученика. Они оценивают заданный контракт, а не способ реализации, и не предназначены для защиты от намеренного обхода.

После завершения, ошибки, остановки или тайм-аута Worker уничтожается, Blob URL освобождается. Лимит 3 секунды включает запуск, ваш код и проверки. До 20000 символов исходника и 32000 символов вывода. Состояние программы между запусками не сохраняется. console.log/info/warn/error/debug поддерживаются как текстовый вывод; объекты сериализуются в JSON, циклические ссылки обозначаются [Circular]. Это упрощённая консоль, без интерактивного инспектора и форматирования %s.

Асинхронные операции нужно ожидать через await/возвращённый Promise. Неожидаемые таймеры и незавершённые фоновые Promise не обслуживаются после возврата результата: Worker сразу завершается. Частичный вывод при ручной остановке/тайм-ауте не доставляется. Точная строка ошибки не выводится из-за обёртки и различий браузерных стеков; показываются тип и сообщение.

CSP запрещает внешние подключения; код отображается через textContent. **Worker не является защищённой средой для чужого вредоносного кода**: у него нет DOM/localStorage, но он работает в origin страницы, может иметь другие API хранилища (например, IndexedDB) и расходовать память. Жёсткой квоты памяти нет. Используйте только свой учебный код; это не сервис публичного исполнения программ. Проект не содержит аккаунтов, секретов, аналитики, серверного API, облака и автоматической отправки данных.

## Сохранение

Ключ localStorage — `js-workshop-v1`: последний урок, отметки и исходники каждого занятия. Очистка браузера удаляет прогресс; смена порта/браузера создаёт отдельное сохранение. Одна активная вкладка на адрес: последняя запись из другой вкладки может перезаписать черновики.

При отказе записи сайт продолжает работу в памяти и показывает предупреждение. Повреждённая/несовместимая запись не перезаписывается. Для ручного восстановления сначала сохраните исходную запись, затем удалите только этот ключ средствами браузера. Экспорта и синхронизации нет.

## Устройство и проверки

- `lessons.js` — материалы и проверяемые контракты.
- `worker.js` — исходник среды выполнения, текстовая консоль и async-проверки.
- `runner.js` — жизненный цикл Worker, остановка и тайм-аут.
- `app.js`, `index.html`, `style.css` — интерфейс и сохранение.

Из папки проекта:

```bash
node --check app.js
node --check runner.js
node --check worker.js
node --check lessons.js
node tests/content-checks.cjs
```

27 Node-тестов, включая 76 учебных вариантов. `tests/browser-checks.js` — async-функция для существующего Playwright page: создаёт изолированные browser contexts, требует сервер на 8770; зависимости проекта для неё не устанавливаются. Результат — `tests/browser-results.json`, подробности — [проверки.md](проверки.md).

Учебная оболочка адаптирована из локальной Python-мастерской; исходники прежних проектов не менялись. Источники для самостоятельного чтения: [JavaScript Guide](https://developer.mozilla.org/ru/docs/Web/JavaScript/Guide), [Worker](https://developer.mozilla.org/en-US/docs/Web/API/Worker), [AsyncFunction](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/AsyncFunction).
