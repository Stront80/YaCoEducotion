# Проверки JavaScript-мастерской

Дата: 2026-11-26. Менеджер, дизайнер и разработчик работали последовательно в одном сеансе. Независимого внешнего ревью нет.

## Код и задания

- Проверки синтаксиса `node --check` для app.js, runner.js, worker.js, lessons.js, tests/browser-checks.js прошли.
- `node tests/content-checks.cjs`: **27 тестов прошли**. Для 19 занятий проверены решение, альтернатива, старт и ошибочная программа — 76 вариантов. Корректные решения принимаются, старт/ошибки отклоняются.
- Проверены синтаксическая ошибка, лимит вывода, циклические объекты/BigInt/undefined, ожидаемая асинхронность, независимость запусков, ошибка внутри условия проверки, завершение зависшего Node Worker и следующий запуск.
- Node проверяет код и контракты в worker_threads с небольшим адаптером self/postMessage. Это не замена браузерной проверке среды.

## Chromium / Playwright

[Сценарий](tests/browser-checks.js), [фактический результат](tests/browser-results.json). Проверки выполнялись в отдельных browser contexts, не используя прогресс пользователя.

- **19/19 занятий** пройдены через редактор и кнопку «Проверить». Также для каждого занятия в настоящем браузерном Worker проверены альтернативное решение, старт и ошибка.
- Просмотр решения не отмечает прохождение; перенос работает. Отмена/подтверждение сброса работают, отметки остаются.
- Прогресс 19/19 и код итогового проекта восстановлены после reload.
- Остановка бесконечного цикла освобождает интерфейс; следующий запуск работает.
- Цикл и никогда не завершающийся Promise остановлены тайм-аутом 3 с; после тайм-аута новый запуск успешен.
- Синтаксические ошибки и лимит вывода имеют понятные сообщения. HTML в выводе остаётся текстом.
- В Worker отсутствуют document/window/localStorage. Попытка fetch к тестовому внешнему адресу заблокирована CSP до сетевого запроса. Это не утверждение полной изоляции origin/API хранилища; ограничения описаны в README.
- Повреждённая запись сохранена нетронутой; отказ setItem показывает предупреждение, занятия продолжают работать.
- Tab выходит из редактора, мобильные вкладки переключаются стрелкой и Home.
- На ширинах 1440/1024/768/390/320 px ширина документа равна ширине окна.
- При тексте 200% теория действительно 32px, переполнения страницы на 1440px нет.
- В сценарии нет ошибок страницы и внешних сетевых запросов. Ожидаемое сообщение CSP от специально запрещённого fetch не считается ошибкой приложения.

Техническая локальная готовность подтверждена, пользовательская оценка курса ещё не получена (TASK-114). Нет DOM, обычной глобальной script-области, модулей, интерактивного console-инспектора и обслуживания неожидаемых фоновых операций. Среда не предназначена для вредоносного кода, квоты памяти нет.
