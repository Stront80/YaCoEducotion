# Ubuntu-мастерская

Неофициальный русскоязычный тренажёр основ терминала для новичков: 18 уроков и итоговая практика. Работает как локальный симулятор. Ubuntu, Bash, Docker и виртуальная машина для использования сайта не нужны.

## Запуск

Из корня рабочего пространства:

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory приложение/ubuntu-trainer
```

Откройте **http://127.0.0.1:8766/**. Остановка — Ctrl+C. Или из папки проекта:

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

Если порт занят, выберите другой. Сохранение связано с браузером и адресом, включая порт: смена порта создаёт отдельное сохранение. `file://` не является проверенным способом запуска. Доступ из локальной сети не настраивался. Не запускайте сервер из корня всего рабочего пространства: сайт не требует доступа к соседним проектам.

## Как учиться

1. Выберите урок, прочитайте короткое объяснение и задачу.
2. Введите команду без начального знака `$`, нажмите Enter или «Выполнить». Вводите по одной строке.
3. Сверьте вывод и виртуальные файлы, затем нажмите «Проверить задание».
4. Если нужно, раскройте подсказку или разбор решения. Решение ничего не запускает автоматически.
5. На телефоне используйте вкладки «Урок», «Терминал», «Файлы».

Стрелки вверх/вниз в поле команды перелистывают историю. Ctrl+L или «Очистить экран» очищают только вывод, не файлы и прогресс. Tab переводит фокус, без автодополнения. Мобильные вкладки переключаются стрелками, Home и End. Памятка под курсом подставляет текст команды без выполнения.

«Сбросить урок» после подтверждения восстанавливает его виртуальную среду и историю. Отметка о ранее выполненном уроке остаётся. Каждый урок имеет независимые файлы; изменения между уроками не переносятся. Просмотр файла через панель не заменяет практику cat/ls, когда это требуется заданием.

## Программа

- Первые шаги: `pwd`, `ls`, `cd`, пути, `mkdir`, `touch`, `cat`.
- Файлы и текст: `cp`, `mv`, `rm`, `rmdir`, `echo`, перенаправление, `head`, `tail`, `grep`.
- Поиск и инструменты: `find`, конвейер, `wc -l`, основы прав `chmod`, знакомство с APT/процессами/справкой.
- Итог: структура рабочей папки, резервная копия заметок, фильтрация журнала, права, очистка временного файла и навигация.

## Что симулируется

Команды разбирает JS-движок с фиксированным набором операций, без eval, запуска shell, запросов к API или доступа к реальной файловой системе. Ввод не отправляется на сервер. Сервер только раздаёт файлы сайта.

Поддерживаются обычные аргументы, одинарные/двойные кавычки, экранирование, `~`, `.`, `..`, абсолютные пути, конвейер до 5 команд и одно завершающее `>`/`>>`. Список команд/параметров смотрите через `help`, `help имя` или `имя --help`.

В отличие от настоящей Ubuntu:

- Это подмножество команд, не ОС и не Bash. Нет переменных, подстановок, скриптов, `;`, `&&`, фоновых задач, shell glob, ссылок и сети. find поддерживает только шаблоны `*` и `?`; grep выполняет буквальный поиск, без регулярных выражений.
- ls не показывает служебные записи `.` и `..`; время, реальные размеры в байтах, владельцы/группы и локали полноценно не моделируются. cp/mv не сливают существующие каталоги. Перенос/удаление текущей папки запрещены в учебной модели.
- Изменения разрешены только внутри `/home/student`. Права упрощены до битов владельца, фиксированного пользователя student и защищённых путей. chmod принимает три восьмеричные цифры, без символьной записи и ACL. Панель файлов — визуальный инспектор данных, не системный файловый менеджер.
- `sudo` разрешён только для учебного APT и не выдаёт реальных прав. APT имеет каталог tree/nano/curl, не требует пароля, ничего не скачивает. До install учебное упражнение требует update. После установки реализована только команда tree; редактор nano и сеть curl не моделируются.
- Процессы условные, PID фиксированы, kill немедленно удаляет учебную запись; процессы 1 и 120 защищены.
- Учебная строка атомарна: ошибка отменяет изменения всей введённой строки. Настоящая оболочка не гарантирует такого отката. Вывод диагностик адаптирован на русский.
- Лимиты: 2000 символов ввода, 256 узлов, 64000 символов файла/вывода и 1 млн символов общего текста файлов. Старые наблюдения ограничены 200 событиями; если слишком долго экспериментировать, раннее наблюдение нужно повторить перед проверкой.

## Сохранение

localStorage, ключ `ubuntu-workshop-v1`: выбранный урок, завершённые занятия, виртуальное состояние, черновик ввода и последние 60 команд/записей вывода каждого посещённого урока. Пароли и реальные данные вводить не требуется. Очистка данных браузера удалит прогресс; аккаунтов и синхронизации нет. Не открывайте несколько активных вкладок для одного сохранения: последняя запись заменяет предыдущую.

При недоступном/переполненном хранилище сайт продолжает работу в памяти с предупреждением. Повреждённая или неизвестная версия записи не перезаписывается; для восстановления можно отдельно сохранить исходное значение и удалить только ключ `ubuntu-workshop-v1` через инструменты браузера.

## Разработка и проверки

HTML/CSS/JS без зависимостей и сборки. package.json фиксирует CommonJS для тестов, чтобы не наследовать тип модулей внешней рабочей папки; установка пакетов не нужна.

```bash
node --check engine.js
node --check lessons.js
node --check app.js
node tests/engine.test.cjs
```

`engine.js` экспортирует `Terminal`: `run(строка) → {output,error,status}`, `snapshot()` и `Terminal.restore(снимок)`. `lessons.js` хранит материалы/сценарии и экспортирует `check(урок,состояние) → [{label,pass}]`. В браузере доступны UbuntuSim/UbuntuCourse; публичного серверного API нет.

`tests/browser-checks.js` — async-функция для существующего Playwright, принимающая page. Создаёт изолированные тестовые browser contexts, проходит все занятия и закрывает их. Сервер должен работать на порту 8766. Результат — `tests/browser-results.json`, подробности — [проверки.md](проверки.md). Скриншоты — `screenshots/`.

## Источники и ограничения проверки

Авторские учебные задания, общие сведения сверены с первичными материалами Ubuntu:

- [Командная строка для начинающих](https://ubuntu.com/desktop/docs/en/latest/tutorial/the-linux-command-line-for-beginners/).
- [Памятка CLI](https://ubuntu.com/server/docs/reference/cli-cheatsheet/).
- [Управление пакетами](https://ubuntu.com/server/docs/how-to/software/package-management/).

Курс не привязан к конкретному выпуску Ubuntu, не является официальным курсом Canonical. Вывод адаптирован для обучения. Реальная практика отличается от симуляции: не переносите команды установки, удаления и изменения прав на рабочую систему автоматически.

Проверен Chromium. Firefox, Safari, реальные телефоны и скринридеры не проверялись. Педагогическая эффективность требует пользовательской оценки. Публикации и отправки данных нет.
