# Проверки Python-мастерской
Дата: 2026-11-26. Последовательно в одном сеансе: менеджер, дизайнер, разработчик, дизайнер и менеджер. Независимого внешнего ревью не было.

## Локальные проверки

- `node --check`: app.js, runner.js, worker.mjs, lessons.js — успешно.
- `python3 tests/test_course.py`: 5 тестов unittest успешно, внутри проверены 19 уроков / 76 учебных вариантов (решение, альтернатива, старт, ошибочная печать), структура курса, ошибки с номерами строк, input/вывод/лимит и отдельные пространства имён.
- `python3 tests/check_vendor.py`: размеры и SHA-256 шести файлов среды и двух лицензий соответствуют manifest.json. Выпуск Pyodide 314.0.8 скачан с официального GitHub по разрешению пользователя; системной установки не было. В браузере Python сообщил версию 3.14.2.

## Chromium / Pyodide

[Сценарий курса](tests/browser-course.js), [результат](tests/course-results.json):

- Все 19 занятий пройдены через настоящее поле редактора и кнопку проверки; итог 19/19, код проекта и прогресс восстановились после reload.
- Для каждого занятия альтернативное решение принято, старт и ошибочная программа отклонены. Всего 76 вариантов, включая 19 решений UI.
- В интерфейсе каждый запуск создавал отдельный Worker. Для дополнительных 57 фиксированных образцов тест использовал один загруженный Worker, но отдельный namespace Python на запуск. Это ускоряет тест и не меняет приложение.
- Открытие решения не засчитало урок. Внешних сетевых запросов и ошибок страницы в этом сценарии нет.

[Поведенческий сценарий](tests/browser-behavior.js), [результат](tests/behavior-results.json):

- Подтверждение/отмена сброса, перенос решения без автоматического зачёта, ввод нескольких строк и пустой вход.
- HTML в выводе отображается как текст. Переменные между отдельными запусками не сохраняются. Ошибка на второй строке показала правильный номер.
- EOFError сообщает о нехватке входа; вывод 40000 символов остановлен на 32000 с OutputLimitError.
- Настоящий бесконечный цикл остановлен кнопкой; следующий запуск успешен. Отдельно сработал тайм-аут 5 секунд, повтор загрузки восстановил выполнение.
- Черновики кода и входа восстановились после reload. Повреждённое хранилище: предупреждение, исходная запись сохранена. Отказ setItem: предупреждение, продолжение работы.
- Ширины 1440, 1024, 768, 390, 320 px: scrollWidth равен ширине окна. Мобильные вкладки работают, проверены стрелка и Home.
- Текст 200%: основная теория действительно стала 32 px, горизонтального переполнения на 1440 px нет.
- Ошибка загрузки Worker была специально воспроизведена в отдельном контексте: появился понятный статус и кнопка повтора. В обычном сценарии pageErrors и внешних запросов нет.

## Ограничения и результат

Worker не является защищённым контейнером для чужого вредоносного кода; отсутствует отдельная квота памяти. Дополнительные пакеты, произвольная сеть и графические приложения не входят в курс. Проверки учебные, не защищены от намеренного обхода. Состояние интерпретатора не сохраняется между запусками. Другие браузеры, реальные телефоны, скринридер, несколько активных вкладок и педагогическая эффективность не проверялись.

Локальная техническая готовность подтверждена. Данные проекта не публиковались и код не отправлялся внешним сервисам; разрешённое скачивание зависимости выполнено. QA-сервер после завершения останавливается. Оценка пользователя — TASK-096 на согласовании.
