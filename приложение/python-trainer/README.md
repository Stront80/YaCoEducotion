# Python-мастерская

Русскоязычный интерактивный курс для новичков: 18 уроков и итоговый анализатор расходов. Редактор, настоящий Python в браузере, входные данные, вывод и ошибки, подсказки/разбор, проверка результата и сохранение прогресса. Аккаунт не нужен.

## Запуск

Из корня рабочего пространства:

```bash
python3 -m http.server 8767 --bind 127.0.0.1 --directory приложение/python-trainer
```

Откройте **http://127.0.0.1:8767/**. Остановка сервера — Ctrl+C.

Либо из папки проекта:

```bash
python3 -m http.server 8767 --bind 127.0.0.1
```

Если порт занят, выберите другой. Прогресс связан с браузером и адресом, включая порт. Не запускайте сервер из корня всего рабочего пространства — сайту не нужны соседние проекты. Открытие через `file://` не поддерживается: модули, Worker и WASM требуют HTTP. Python используется здесь только как сервер статических файлов, код ученика на нём не выполняется.

Pyodide уже находится в `vendor/`, дополнительных скачиваний и pip/npm install для использования сайта не требуется. Современный браузер должен поддерживать WebAssembly и модульные Workers. При первом открытии дождитесь статуса «Python готов». В этой версии используется Pyodide 314.0.8 с Python 3.14.2, примерно 13 МиБ файлов среды.

## Как учиться

1. Выберите любой урок и прочитайте задание.
2. Напишите код. Для блока после `if`, `for`, `while`, `def` используйте четыре пробела.
3. Если нужен `input()`, подготовьте входные строки в отдельном поле: один вызов читает одну строку. Пустая строка задаётся переводом строки; пустое поле означает отсутствие входных строк.
4. Нажмите «Запустить» или Ctrl+Enter / Cmd+Enter в редакторе. Результат будет в области вывода.
5. Нажмите «Проверить». Проверки оценивают вывод, переменные и функции на разных входах. Простая печать результата вместо нужной функции не проходит её проверки.
6. Если программа зависла — «Остановить». По истечении пяти секунд выполнения она остановится автоматически. При ошибке загрузки доступна кнопка повтора.

На телефоне переключайте «Задание», «Код», «Результат». Стрелки/Home/End управляют вкладками; Tab в редакторе переводит фокус, не вставляет отступ и не создаёт клавиатурную ловушку. Есть позиция строки/столбца, видимый фокус и подписи полей.

Подсказка и разбор раскрываются по запросу. Просмотр и перенос решения не завершают урок; перенос в редактор требует подтверждения замены. Восстановление старта также требует подтверждения. Ранее полученная отметка прохождения остаётся после экспериментов и сброса кода.

## Программа

- Первые программы: print, переменные, арифметика, строки, input, преобразование типов.
- Решения и повторения: if/else/elif, логические условия, for/range, while, накопление суммы.
- Данные и функции: списки, словари, def/return, параметры по умолчанию, фильтрация, try/except.
- Проект: `analyze_expenses(items)` возвращает общую сумму, название самой дорогой покупки и суммы по категориям. Входные данные — корректные покупки с неотрицательными целыми суммами; при равенстве выбирается первая покупка, пустой список обрабатывается отдельно. Это учебные условные суммы, не приложение для финансового учёта.

## Как устроено выполнение

Pyodide исполняет настоящий Python 3.14.2 в модульном Worker. Каждый запуск получает новый Worker, пространство имён и виртуальную файловую систему: изменения переменных, модулей и файлов предыдущей программы не сохраняются. Поэтому следующему запуску может потребоваться несколько секунд на подготовку; браузер может кэшировать файлы среды.

`input()` заменён чтением заранее подготовленных строк. `print` и stderr перенаправлены в ограниченный текстовый вывод. Обычные ошибки показываются с типом, сообщением, номером строки и кратким пояснением на русском. Каждый запуск имеет отдельный идентификатор, устаревшие ответы не принимаются.

Остановка завершает Worker через terminate; SharedArrayBuffer и специальные заголовки сервера не нужны. Тайм-аут выполнения — 5 секунд после загрузки Python, ожидание загрузки — до 30 секунд. Лимиты: 20000 символов исходного кода, 10000 символов входа и 32000 символов вывода. Отдельная квота памяти не реализована: очень большие объекты могут исчерпать ресурсы браузера.

Сервер только раздаёт файлы проекта, серверного API для исполнения кода нет. CSP ограничивает ресурсы и подключения этим локальным адресом; отсутствуют аналитика, CDN, автоматическая загрузка пакетов и отправка кода во внешние сервисы. `jsglobals` не предоставляет учебному коду глобальные объекты страницы. Python видит виртуальную файловую систему Pyodide, не файловую систему компьютера. Worker отделяет вычисления от UI, но не является полной защитой от намеренно вредоносных программ: используйте свой учебный код, а не неизвестные чужие программы.

Стандартная библиотека в WebAssembly имеет отличия от настольного Python; многие сторонние/нативные пакеты отсутствуют. pip/micropip, графические окна, серверные процессы и произвольный сетевой доступ не входят в курс. Пакеты из imports автоматически не устанавливаются.

## Сохранение

localStorage под ключом `python-workshop-v1`: последний урок, завершённые занятия, отдельные исходники и входные строки каждого посещённого урока. Результат выполнения не сохраняется: его можно получить повторным запуском. Очистка данных браузера удалит прогресс; облачной синхронизации и резервного экспорта нет. Одновременно используйте одну вкладку для одного адреса: последняя запись может заменить предыдущую.

При недоступном/переполненном хранилище сайт продолжает работать в памяти с предупреждением. Повреждённые или несовместимые записи не перезаписываются. Для ручного восстановления сначала сохраните исходное значение, затем удалите только ключ `python-workshop-v1` средствами браузера.

## Разработка и проверки

`lessons.js` содержит материалы и декларации проверок; `harness.py` — обвязку stdout/input и проверок внутри Python; `worker.mjs` — загрузку локального интерпретатора; `runner.js` — жизненный цикл, таймер и остановку; `app.js` — интерфейс/сохранение. `package.json` фиксирует тип модулей тестов, зависимости отсутствуют.

Из папки проекта:

```bash
node --check app.js
node --check runner.js
node --check worker.mjs
node --check lessons.js
python3 tests/test_course.py
python3 tests/check_vendor.py
```

`test_course.py` исполняет только авторские решения и фиксированные ошибочные примеры в уже установленном CPython, не принимает пользовательские программы. Для браузера есть `tests/browser-course.js` и `tests/browser-behavior.js`: async-функции, принимающие существующий Playwright page и создающие отдельные тестовые browser contexts. Их нужно запускать отдельно, при работающем сервере на 8767. Первая проверяет 19 прохождений через интерфейс и альтернативы/ошибки; вторая — остановку, лимиты, сохранение и адаптивность. Результаты — `tests/*-results.json`. Внешние пакеты тестирования в проект не устанавливались.

Фактические проверки и ограничения: [проверки.md](проверки.md). Снимки интерфейса — `screenshots/`.

## Происхождение зависимостей и материалов

Pyodide скачан с разрешения пользователя из [официального выпуска 314.0.8](https://github.com/pyodide/pyodide/releases/tag/314.0.8). Использованы только файлы для браузера; системные исполняемые файлы из архива не устанавливались. Происхождение, размеры и SHA-256 — `vendor/manifest.json`. Лицензии — [Pyodide MPL 2.0](vendor/PYODIDE-LICENSE) и [CPython](vendor/PYTHON-LICENSE).

Авторские задания сверены с [учебником Python](https://docs.python.org/3/tutorial/). Размещение и Worker API — по [документации Pyodide](https://pyodide.org/en/stable/usage/webworker.html). Интерфейс использует адаптированные компоненты локальной Веб-мастерской, исходный проект не менялся. Изображения, внешние шрифты и генерация графики не использовались.

Проверен Chromium. Firefox, Safari, физические телефоны, скринридер и субъективная эффективность обучения пока не проверялись. Сайт не опубликован.
