# Python-мастерская — бриф
Дата: 2026-11-26. Поручение трём ролям; пользователь разрешил скачать Pyodide из официального GitHub в vendor после предложения курса для новичков.

Отдельный локальный русскоязычный сайт: 18 уроков и итоговый проект, настоящий Python в браузере, редактор, вывод и ошибки, подсказки/разбор, проверка заданий и локальный прогресс. Формат первой версии принят из предложения перед ответом «разрешаю». Сроки и бюджет не назначались.

Три блока по шесть занятий: первые программы; условия и повторения; структуры данных и функции. Итоговый проект — анализатор расходов: функция, принимающая список покупок и возвращающая итоговую сумму, самую дорогую покупку и суммы по категориям. Уроки доступны сразу, черновики сохраняются отдельно.

Pyodide хранится в проекте и загружается только с локального сервера. Выполнение в модульном Worker, остановка кнопкой и тайм-аут. input читает заранее введённые строки из отдельного поля. Проверки оценивают вывод/значения и функции на нескольких входах, а не совпадение кода с образцом. Просмотр решения не завершает урок.

Нет аккаунтов, backend, установки системных программ, внешних шрифтов/CDN, публикации и отправки кода. Дополнительные Python-пакеты не устанавливаются. Код запускается только по действию пользователя, предназначен для собственных учебных программ. Worker отделяет вычисления от интерфейса, но не является границей безопасности от намеренно вредоносного кода.

Критерии: решения/альтернативы принимаются, старт и ошибки отклоняются; понятные ошибки Python с номером строки; прерывание зависшего кода, ограничение вывода, работоспособное восстановление; сохранение после reload и сообщения об отказе; компьютер/телефон/клавиатура и текст 200% проверены. Общие задачи в проект/задачи.md.
