# Дизайн Python-мастерской
Дата: 2026-11-26. Последовательная роль дизайнера, TASK-092.

Светлая оболочка, глубокий синий #284c9a и тёплый жёлтый #f5cf61 как акценты; тёмный редактор #17243a. Собственный знак «py», без копирования официального логотипа. Системный шрифт и системный моноширинный, размеры в rem: основной 16px, регулярные подписи от 14px, вторичные метаданные от 12px.

Шапка: название, локальный режим, статус Python. Вступление с прогрессом и тремя этапами. Слева — программа с отметками. Основная карточка: теория/задание, подсказка, разбор. Справа редактор с номером строки/столбца, кнопками запуска, остановки и проверки. Ниже — ввод для input и вывод программы/ошибки. Результаты проверки видны вне мобильных вкладок. Следующий/предыдущий урок внизу.

На телефоне программа сворачивается, области «Задание», «Код», «Результат» переключаются вкладками; индикация выполнения и остановка остаются доступны. На компьютере текст и практика рядом, на планшете последовательно. Нет автоматического запуска при редактировании.

Редактор — textarea с нативной навигацией: Tab переводит фокус, отступы вводятся пробелами. Ctrl+Enter/Cmd+Enter запускает, стрелки/Home/End переключают вкладки. Все поля подписаны, видимый focus-visible, ошибки имеют текст, результат — aria-live, reduced-motion учитывается. Восстановление старта требует подтверждения. Открытие решения не исполняет и не подставляет код; отдельная кнопка копирования решения в редактор с подтверждением замены.

Состояния: загрузка/готовность/ошибка запуска Python с повтором, выполнение, остановка/тайм-аут, вывод, ошибка с номером строки, частично выполненные условия, успех, завершение курса, отказ сохранения. Переполнение кода/вывода только внутри областей, элементы управления переносятся. Проверить широкую/узкую версии и увеличение текста, не заявлять стандарт доступности без полного аудита.
