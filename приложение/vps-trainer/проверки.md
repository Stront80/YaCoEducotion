# Проверки VPS-мастерской

Дата: 2026-11-26. Менеджер, дизайнер, разработчик, дизайнер и менеджер работали последовательно в одном сеансе. Независимого внешнего ревью нет.

## Модель и курс

- Синтаксис engine.js, lessons.js, app.js и tests/browser-checks.js проверен Node.
- `node tests/engine.test.cjs`: **45 тестов прошли**. Для 19 занятий проверены старт, решение, альтернатива и ошибка — 76 вариантов. Успешные снимки восстановлены и сравнены целиком.
- Проверены разделение клиента/сервера, проверка host key, адресные ограничения, sudo после нового входа, отказ без полномочий, файл SSH против активной конфигурации, неверная/устаревшая проверка, первое значение директивы, password и keyboard-interactive отдельно, сохранение старого сеанса, права ключей, UFW-подтверждение/порядок правил/потеря и восстановление доступа.
- Проверены reboot/автозапуск/неверный SSH при загрузке, возврат к snapshot без удаления внешней копии, права владельца архива для scp, отдельная распаковка, отказ shell-подстановок без изменений, лимиты, сохранение редактора/подтверждения и повреждённые снимки.
- 25 трасс × 200 команд/действий = **5000**; после каждого шага VPS.restore проверял структуру. Это проверка инвариантов модели, не случайная проверка семантической совместимости с Ubuntu.

## Chromium / Playwright

[Сценарий](tests/browser-checks.js), [результат](tests/browser-results.json). Изолированные browser contexts, собственные учебные данные.

- **19/19 занятий** пройдены через поле ввода, кнопки провайдера, подтверждения и редактор конфигов. Старт каждого не проходит, просмотр решения не засчитывается.
- Прогресс 19/19 и полное состояние итогового VPS сохранились после reload. Отмена/подтверждение сброса проверены, отметки остаются.
- Намеренная блокировка UFW: свежий SSH не входит, старый сеанс остаётся, консоль возвращает правило и доступ. Исправление после ошибочного порядка не засчитывает учебную цель «разрешить до enable».
- Неверный SSH-файл не применился. Несохранённый текст редактора восстановился после reload, отмена не изменила файл.
- HTML в команде/выводе остаётся текстом, история вверх/вниз работает, Tab выводит фокус из поля. Памятка только вставляет текст.
- Повреждённая запись localStorage сохранена нетронутой, отказ записи показывает предупреждение и не мешает пройти первое задание.
- Ширины 1440/1024/768/390/320 px: горизонтального переполнения страницы нет. Мобильные вкладки переключаются стрелкой и Home.
- Текст 200% на 1440 px: теория реально 32px, переполнения страницы нет. После визуального просмотра увеличена ширина карты VPS относительно текста и исправлены переносы заметок/длинных заголовков.
- Ошибок страницы и внешних запросов сайта в сценарии нет.

После изменения мобильных кнопок и сворачивания панели полный браузерный сценарий повторён успешно. Последние поправки переносов проверены целевым просмотром/измерением заголовков и снимком. Временный QA-сервер один раз завершился в среде; после повторного запуска снимки пересняты с работающей страницей.

## Готовность и ограничения

Локальная техническая готовность подтверждена. Пользовательская оценка курса ещё не получена — TASK-120. Источники и границы модели описаны в README. Настоящие SSH/UFW/apt/systemd не запускались; реальной Ubuntu/VPS для сопоставления не было. Полная совместимость не доказана.

Нет настоящего SSH, сети, криптографии/паролей, cloud-firewall, DNS, отдельных IPv6-правил, полного sshd_config/Match/cloud-init/socket activation, согласованных backup БД и настоящих сервисов. Реальные телефоны/IME/скринридеры, другие браузеры и эффективность обучения не проверены. Установок программ/зависимостей, системных изменений, публикации и внешней отправки данных не было. QA-сервер после проверок останавливается.
