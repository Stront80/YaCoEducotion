# Vim-мастерская

Неофициальный русскоязычный тренажёр для новичков: 18 уроков и итоговая практика. Локальная учебная модель Vim без зависимостей, установки редактора и серверного исполнения команд. Режимы, курсор, выделение, движения и изменение текста работают в одном JS-движке.

## Запуск

Из корня рабочего пространства:

```bash
python3 -m http.server 8768 --bind 127.0.0.1 --directory приложение/vim-trainer
```

Откройте **http://127.0.0.1:8768/**. Остановка — Ctrl+C.

Либо из папки проекта:

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

Если порт занят, выберите другой. Сохранение связано с браузером и адресом, включая порт: смена порта создаёт отдельный прогресс. Не запускайте сервер из корня всего рабочего пространства — сайту не нужны соседние проекты. `file://` не является проверенным режимом. Установка npm-пакетов, настоящего Vim или настройка сервера не требуются для обучения.

## Как учиться

1. Выберите урок, прочитайте объяснение и задачу.
2. Нажмите на редактор или кнопку «К редактору»: только после фокуса он принимает команды.
3. В Normal используйте латинскую раскладку. В Insert можно вводить русский текст. Escape возвращает Normal.
4. Нажмите «Проверить задание». Проверяются текст, курсор, режим и требуемые наблюдения — альтернативные решения допускаются.
5. При необходимости откройте подсказку или разбор. Решение ничего автоматически не выполняет и не завершает урок.

Обозначения в решении: `<Esc>` — клавиша Escape, `<CR>` — Enter, `<C-r>` — Ctrl+R. Остальные символы набираются как показано. Комбинация `dw` — сначала d, затем w, без Enter. Для `:w` или `/cat` нужен Enter. При незавершённой комбинации она видна рядом с названием режима.

Tab и Shift+Tab выводят фокус из редактора. Ctrl+R выполняет redo только внутри редактора; за его пределами действует обычное поведение браузера. Другие системные сочетания не перехватываются. Стрелки также двигают курсор. Щелчок мышью передаёт фокус, но не переставляет курсор — для этого предназначены команды движения.

На телефоне доступны вкладки «Урок», «Практика», «Памятка», экранные специальные/буквенные клавиши и отдельное поле текста. Включите Insert кнопкой i, подготовьте текст в поле и нажмите «Ввести текст», затем Esc. В поле можно готовить и строку поиска/Ex-команды после / или :, но без перевода строки: Enter нажимается отдельно. Сам текст в поле не считается командой до нажатия кнопки.

Памятка сворачивается на компьютере и открывается на своей мобильной вкладке. Вкладки переключаются стрелками/Home/End. Редактор поддерживает input/composition для экранных клавиатур, однако физические телефоны и конкретные IME пока не проверены.

## Программа

- Первые движения: Normal/Insert, Esc, h/j/k/l, i/a/A, o/O, виртуальные сохранение и выход.
- Редактируем уверенно: слова w/b/e, границы строки 0/^/$, gg/G и счётчики, x/r, операторы удаления, удаление строк.
- Работаем с текстом: регистр yy/p/P, undo/redo, поиск / и n/N, замена cw/c$, символьный и построчный Visual.
- Итог: отредактировать заметку, исправить слово, удалить строку и сохранить нужный текст.

Все уроки доступны сразу, каждое занятие имеет независимое состояние. Кнопка сброса после подтверждения восстанавливает текст, виртуальное сохранение, регистр и undo/redo. Отметка ранее выполненного урока остаётся.

## Что поддерживает модель

- Normal: h/j/k/l и стрелки; w/b/e; 0/^/$; gg/G и числовой переход nG; счётчики до 99 для поддерживаемых движений/операторов.
- Insert: i/a/I/A/o/O, текст, Enter, Backspace, Delete, стрелки, Escape. Ввод до Esc — один шаг отмены.
- Операторы d/y/c с w/b/e/0/^/$/h/l/j/k/gg/G и удвоением dd/yy/cc. Учитывается различие включающего/исключающего конца; cw на слове сохраняет следующий пробел. D/C — сокращения d$/c$.
- x/Delete, r с заменяемым символом, p/P, u и Ctrl+R. Есть один внутренний регистр, символьный или построчный.
- Visual v и V: движения, y/d/x/c, Escape. Выделение символьного диапазона включает символ под курсором.
- Буквальный поиск /текст + Enter, n и N, с учётом регистра и оборачиванием.
- Виртуальные Ex: :w, :q, :q!, :wq, :x и краткий :help. Вкладка браузера не закрывается, реальные файлы не читаются и не записываются. «Открыть файл» восстанавливает сохранённый виртуальный текст, очищая историю редактирования.

**Это подмножество Vim, не полный движок.** Нет макросов, именованных/системного регистров, плагинов, нескольких файлов/окон, точечного повтора, текстовых объектов, Visual Block, регулярных выражений и большинства Ex-команд. Неизвестные команды сообщают об ограничении. Не все сочетания числовых префиксов из настоящего Vim поддерживаются: повтор Insert, например 3i, явно отклоняется. Автоматические отступы выключены, форма табуляции и экранные колонки не моделируются. Вертикальные движения учитывают логические строки, не переносы экрана.

Индексы курсора считаются в Unicode code points, не в байтах или графемах. Кириллица и отдельный emoji не разрезаются, но комбинируемые символы, широкие графемы, табуляция и некоторые переходы между пустыми строками могут отличаться от настоящего Vim. Буфер хранится как строки без отдельного признака завершающего перевода строки файла. Сравнение с Vim выполнено для 24 конкретных примеров, а не для всего набора возможных комбинаций.

Ограничения: 20000 UTF-16 единиц текста, 400 строк, до 2000 символов за одну блочную вставку, до 50 шагов undo и redo, последние 100 наблюдений. Очень старые наблюдения урока при долгих экспериментах могут потребовать повторения действия. Учебные проверки не защищены от намеренного обхода и не являются экзаменом.

## Два разных сохранения

**Виртуальный файл** изменяется командами :w/:wq/:x. Метка `[+] Есть изменения` означает, что текст буфера отличается от этой сохранённой версии. :q! отбрасывает изменения именно относительно виртуального файла.

**Автосохранение прогресса браузером** сохраняет текущее состояние даже без :w: буфер, режим, курсор, регистр, поиск, историю undo/redo, виртуальное сохранение и отметки занятий. Оно нужно, чтобы после перезагрузки продолжить урок. Эти механизмы специально разделены.

localStorage: ключ `vim-workshop-v1`. Очистка данных браузера удаляет прогресс; аккаунтов, облака и экспорта нет. Используйте одну активную вкладку на адрес: последняя запись может заменить предыдущую. При недоступном/переполненном хранилище сайт работает в памяти и показывает предупреждение. Повреждённая/неподдерживаемая запись не перезаписывается. Для ручного восстановления сначала сохраните исходное значение, затем удалите только ключ `vim-workshop-v1` средствами браузера.

## Устройство и проверки

`engine.js` — модель: `VimModel`, `key(клавиша)`, `type(текст)`, `snapshot()`, `VimModel.restore(снимок)`. `feed(нотация)` используется только авторскими тестами; UI не исполняет сохранённые решения. `lessons.js` содержит материалы и `check(урок,состояние) → [{label,pass}]`. `app.js` связывает физический/экранный ввод и отображение. Серверного API нет. Все строки вставляются в DOM как текст, без eval/HTML-исполнения. CSP запрещает внешние подключения.

Из папки проекта:

```bash
node --check engine.js
node --check lessons.js
node --check app.js
node tests/engine.test.cjs
```

Если Vim уже установлен, доступно дополнительное сравнение:

```bash
python3 tests/compare_vim.py
```

Этот тест создаёт собственные файлы в `/tmp/vim-trainer-compare-*`, запускает `vim -Nu NONE -U NONE -i NONE -n -es` без пользовательских настроек, swap и viminfo. Пользовательские файлы не открывает; временные файлы оставляет без удаления. Отчёт — `tests/native-results.json`. Для использования сайта установленный Vim не нужен.

`tests/browser-checks.js` — async-функция для существующего Playwright page. Создаёт отдельные тестовые browser contexts, проходит 19 занятий и проверяет интерфейс. Нужен работающий сервер на порту 8768. Зависимости тестирования в проект не устанавливались. Отчёт — `tests/browser-results.json`, подробности — [проверки.md](проверки.md).

## Источники и ограничения проверки

Авторские упражнения сверены с установленными официальными справками Vim 9.1: `usr_02.txt`, `usr_03.txt`, `usr_04.txt` и `tutor1.ru` из `/usr/share/vim/vim91/`. Для чтения онлайн: [первые шаги](https://vimhelp.org/usr_02.txt.html), [движения](https://vimhelp.org/usr_03.txt.html), [редактирование](https://vimhelp.org/usr_04.txt.html).

Оболочка использует адаптированные компоненты локальной Веб-мастерской; исходный проект не менялся. Официальные логотипы, внешние шрифты, генерация изображений и скачивание движка не использовались.

Проверен Chromium. Firefox/Safari, физические телефоны, реальные IME, скринридер и субъективная эффективность обучения не проверялись. Сайт не публиковался.
