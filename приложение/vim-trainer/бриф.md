# Vim-мастерская — бриф
Дата: 2026-11-26. Пользователь выбрал первый вариант: учебный симулятор без зависимостей.

Отдельный локальный русскоязычный сайт для новичков: 18 уроков и итоговая практика. Normal/Insert/Visual, движения, операторы, удаление/замена/копирование, отмена/повтор, поиск и виртуальное сохранение/выход. Это явно обозначенное подмножество Vim, без установки настоящего движка, пакетов или доступа к файлам компьютера.

Цикл: объяснение → задача → клавиатурная практика в редакторе → проверка состояния → подсказка/разбор. Проверки смотрят на текст, курсор, режим, виртуальное сохранение и наблюдения, а не на единственную строку команд. Все уроки открыты. Состояния отдельных занятий и прогресс сохраняются в браузере. На телефоне есть экранные специальные клавиши и ввод текста.

Критерии: режимы и последовательные команды работают согласованно, ошибка не выдаётся за успешную команду, начальные/ошибочные состояния не засчитываются, альтернативные решения проходят. Нет глобального перехвата клавиатуры; Tab выводит фокус из редактора, Escape возвращает Normal. Виртуальные :w/:q/:q!/:wq не пишут реальные файлы и не закрывают вкладку. Открытие решения не выполняет команды. Без аккаунтов, сервера приложения, сети и публикации. Браузерный просмотр, тесты движка и сопоставление отдельных команд с установленным Vim без пользовательского vimrc.
