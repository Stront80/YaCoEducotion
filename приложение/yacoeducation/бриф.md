# YaCoEducation: бриф

Дата: 2026-11-26. Пользователь поручил три роли и выбрал добавление «через файл реестра» после предложения локального каталога, общей оболочки и одного запуска.

Объединить семь существующих trainer: web, Ubuntu, Python, Vim, tmux, JS и VPS под брендом YaCoEducation. Общий каталог с поиском/направлениями/прогрессом, навигация вокруг работающих мастерских, единый локальный запуск. Новые мастерские добавляются в workshops.json. Исходники существующих курсов сохраняются.

Сайт локальный, без зависимостей/аккаунтов/публикации. Малый Python-сервер только читает реестр и раздаёт разрешённые ресурсы; ни shell, ни код ученика на сервере не исполняются. Источники подключаются из соседних каталогов приложения по разрешённым маршрутам.

Критерии: доступны все семь курсов; Python/Worker/WASM и веб-sandbox работают по новым путям; общий каталог отражает корректный прогресс и обновляется после выполнения; нет чтения/записи старых origin/портов; добавление тестовой мастерской через реестр проверено; неизвестные пути, traversal, symlink escape и запись HTTP не допускаются. Проверить клавиатуру, мобильный экран и текст 200%.

На общем адресе отдельные localStorage-сохранения; старые порты сохраняют прежний прогресс. Автоматического переноса между origin нет. Полное повторное прохождение всех 133 занятий не требуется: для интеграции проверяются загрузка и выполнение репрезентативных заданий каждой мастерской, собственные проверки курсов остаются в их проектах.
