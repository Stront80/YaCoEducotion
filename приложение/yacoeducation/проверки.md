# Проверки YaCoEducation

Дата: 2026-11-26. Последовательная работа менеджера, дизайнера, разработчика, дизайнера и менеджера в одном сеансе; независимого внешнего ревью нет.

## Реестр, сервер и логика

- serve.py --check: **7 мастерских, 133 занятия**, реестр корректен.
- **11 unittest-тестов**: метаданные, уникальность ID/ключей, lessonIds, неизвестные учебные маршруты, источники вне папки приложений, traversal/двойное кодирование/скрытые пути, symlink escape, отсутствие listing/выдачи документов и серверного кода, доступность Python vendor/harness.
- Реальное добавление тестовой записи к копии реестра проверено: получены 8 курсов, новый source разрешён и его HTML прочитан по новому маршруту. Исходный реестр не менялся. Фикстура сохранена в tests/fixtures, в обычный каталог не включена.
- **11 Node-тестов**: публичная схема/URL, пустой/частичный/полный/повреждённый/недоступный прогресс, неизвестные/дублированные ID, поиск/направление/статус, неизвестный маршрут. ID всех 133 занятий сверены с исходниками семи курсов.
- node --check для app.js/core.js/tests/browser-checks.js прошёл. Python синтаксис проверяется импортом в unittest без записи pycache.

## Chromium / Playwright

[Сценарий](tests/browser-checks.js), [результат](tests/browser-results.json). Использованы отдельные browser contexts, прогресс прежних origin не читался и не менялся.

- **7/7 мастерских** открыты внутри YaCoEducation. В каждой через собственный UI выполнено первое задание: HTML в sandbox, JS в Worker, Python 3.14.2 в локальном Pyodide/WASM, pwd в Ubuntu, Escape в Vim, префикс/справка в tmux, панель/снимок VPS.
- Прогресс каждой обновился в оболочке и карточке; итог 7 отметок. Маркер документа подтвердил, что storage-событие не пересоздало iframe. После reload отметки и недавняя мастерская сохранились.
- Проверены поиск SSH/JS, направления, пустая выдача/сброс, фильтры начатых/пройденных, переход из карточки, переключатель и Back, фокусный режим, отдельный URL, неизвестная мастерская без iframe.
- На узком iframe реально выполнено JS-задание через мобильные вкладки курса.
- Страница/API/основные ресурсы доступны. POST отклонён 405; serve.py, workshops.json, README, tests, скрытый/кодированный путь не выдаются. WASM имеет MIME application/wasm.
- Дополнительная карточка и её маршрут появились из расширенного публичного JSON без правок UI; в этой браузерной проверке API и HTML нового курса подменены локальным Playwright route. Реальный разбор source и его файла проверен отдельно Python-тестом. Текст с <img> не создаёт HTML.
- Повреждённые записи каталога и мастерской сохранены нетронутыми; отказ getItem/setItem показывает предупреждение, каталог и занятие Ubuntu продолжают работать.
- Ошибка API показывает сообщение/повтор; после восстановления ответа каталог загружается.
- Каталог и общая оболочка: ширины **1440/1024/768/390/320**, горизонтального переполнения нет. Текст 200%: описание героя 36px, ширина страницы 1440px.
- В сценарии ошибок страницы и внешних запросов нет.

Это интеграционные проверки, не повторное прохождение 133 занятий. Собственные тесты и ограничения тренажёров остаются в их документации.

## Готовность и ограничения

Локальная техническая готовность подтверждена. Исходники прежних курсов не переписывались. Сохранения общего origin отдельные от прежних портов; миграции нет. Каталог читает отметки completed, но не проверяет полноту внутренних снимков разных движков. Сайты доверенные, один origin не изолирует их друг от друга. Неизвестные типы ресурсов и backend не поддерживаются автоматически.

Другие браузеры, физические устройства/IME, скринридеры и пользовательская оценка не проверены. Установок зависимостей, системных изменений, публикации и внешней отправки исходников не было. Локальный QA-сервер после проверок останавливается. Пользовательская оценка — TASK-126 на согласовании.
