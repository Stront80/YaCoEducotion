# tmux-мастерская

Неофициальный русскоязычный тренажёр для новичков: 18 уроков и итоговая практика. Сессии, окна и панели работают в одной локальной JS-модели. Есть префикс Ctrl+B, экранные клавиши, краткая теория, подсказки/разбор, проверки, история и сохранение состояния занятий.

## Запуск

Из корня рабочего пространства:

```bash
python3 -m http.server 8769 --bind 127.0.0.1 --directory приложение/tmux-trainer
```

Откройте **http://127.0.0.1:8769/**. Остановка — Ctrl+C.

Либо из папки проекта:

```bash
python3 -m http.server 8769 --bind 127.0.0.1
```

Если порт занят, выберите другой. Сохранение связано с браузером и адресом, включая порт. Запускайте сервер только из папки проекта: соседние материалы сайту не нужны. `file://` не является проверенным режимом. Установка tmux, npm-пакетов, Docker или настройка настоящего терминала не требуются.

## Как учиться

1. Выберите урок и прочитайте задачу. Все занятия доступны сразу.
2. Нажмите «К терминалу» или поле ввода. Только в этом поле перехватывается Ctrl+B.
3. Нажмите Ctrl+B, отпустите Ctrl, затем команду: например c. Префикс подсвечивается и действует на следующую клавишу. Это не одновременное Ctrl+B+C.
4. Обычные команды вводите в поле и завершайте Enter. Во внешней оболочке можно создать/подключить сессию; в панели — использовать учебные команды.
5. Нажмите «Проверить задание». Проверка смотрит на структуру и результат, а не точный текст вашего решения.

На телефоне есть вкладки «Урок», «Терминал», «Структура» и экранные клавиши. Полная геометрия терминала сохраняется: на узком экране прокручивайте его внутри по горизонтали. Структура текстом помогает видеть все окна/панели. Специальные клавиши дублируют физическую клавиатуру; пункт выбора сессии можно нажать.

Tab/Shift+Tab выводят фокус из поля, Esc отменяет префикс или режим. Системные сочетания кроме Ctrl+B внутри поля остаются браузеру. Вне поля Ctrl+B не перехватывается. Стрелки управляют панелями только после префикса; в обычной строке они редактируют ввод. Мобильные вкладки переключаются стрелками, Home и End.

В решении `<C-b>` означает Ctrl+B, `<Enter>` — Enter, `<Space>` — пробел; эти обозначения не печатаются буквами. Строка `$ tmux ...` вводится без начального `$`. Для :команды tmux слово tmux не нужно. Просмотр решения ничего автоматически не исполняет.

Кнопка сброса после подтверждения восстанавливает среду занятия и её историю. Отметка ранее выполненного урока остаётся. Каждый урок имеет независимые сессии: изменения между уроками не переносятся.

## Программа

- Сессии и окна: префикс и справка, создание сессии, новое окно, имя окна, переключение, detach/attach.
- Панели и раскладки: панели рядом/сверху и снизу, фокус, zoom, готовая раскладка, подтверждение закрытия.
- Управление средой: несколько сессий, переименование, список выбора, вынос панели в окно, просмотр истории, командная строка tmux.
- Итог: project с editor/logs; в editor три вложенные панели, в logs одна; отключение и восстановление подключения.

## Что симулируется

**Это подмножество tmux, не настоящий терминальный сервер.** Ввод разбирает JS-движок с фиксированными операциями. Нет shell/eval, PTY, процессов ОС, сокетов, SSH, серверных API и доступа к реальной файловой системе. Detach сохраняет данные, не запускает фоновые программы. Закрытие панели завершает только виртуальную запись. Установка программ и запись .tmux.conf отсутствуют.

Иерархия: сессия содержит окна, окно содержит панели и дерево раскладки. Стабильные ID: $ для сессии, @ для окна, % для панели; индексы окон отдельные и могут переиспользоваться после закрытия. Активные окно и панель обозначены в строке статуса, панель имеет выделенную рамку. Вкладки/панели в схеме не переключаются мышью: для обучения используйте команды; интерактивным является отдельный список выбора сессии.

Поддерживаемые сочетания после Ctrl+B:

| Клавиша | Действие |
| --- | --- |
| c, запятая | Создать / переименовать окно |
| n, p, l, цифра | Следующее / предыдущее / последнее / выбранное окно |
| %, двойная кавычка | Новая панель справа / снизу |
| o, Left/Right/Up/Down | Перебор панелей / сосед в направлении |
| z | Включить/выключить zoom |
| Space | Следующая учебная раскладка |
| x, затем y/n | Подтверждение закрытия панели |
| d | Отключиться от сессии |
| s, затем выбор | Переключиться в другую сессию |
| $ | Переименовать сессию |
| ! | Вынести панель в отдельное окно |
| [, затем Up/PageUp | Просмотреть историю |
| ? | Учебная справка |
| : | Командная строка tmux |

Двойной Ctrl+B только отмечает передачу префикса учебной оболочке — полноценная программа внутри панели не моделируется. Режим истории поддерживает Up/Down/PageUp/PageDown и q/Esc. Выделение, поиск по истории, paste buffer и Ctrl+B ] не реализованы. Это отдельно оговорено в уроке.

Команды можно вводить после `tmux` в оболочке или без этого слова в приглашении после Ctrl+B :

- `new-session [-d] [-s имя] [-n окно]`, `attach-session [-t сессия]`, `detach-client`, `list-sessions`.
- `new-window [-d] [-n имя] [-t сессия]`, `rename-window [-t окно] имя`, `rename-session [-t сессия] имя`.
- `next-window`, `previous-window`, `last-window`, `select-window -t окно`.
- `split-window [-h|-v] [-t панель]`, `select-pane [-L|-R|-U|-D|-t панель]`, `resize-pane -Z`.
- `select-layout имя`, `next-layout`, `break-pane`.
- `kill-pane [-t панель]`, `kill-window [-t окно]`, `kill-session [-t сессия]` — виртуальные, команды непосредственно выполняют действие без клавишного подтверждения.
- `switch-client -t сессия`, `list-windows [-t сессия]`, `list-panes`, `list-keys`, `copy-mode`.

Краткие aliases: new, a/attach, ls, neww, splitw, selectw, selectp, renamew, rename, detach, killp, killw, breakp, selectl, lsp, lsw, lsk. Цели окон: индекс текущей сессии, @ID, имя или `сессия:индекс`; панели — %ID, индекс в порядке дерева или `сессия:окно.индекс`. Для select-pane в другом окне сначала выберите окно. У некоторых команд поддерживается только текущий объект; перечисленные флаги — полный набор модели, не справочник настоящего tmux.

Учебная оболочка содержит только `echo`, `pwd`, `whoami`, `clear`, `help`, `demo-log` и `tmux ...`. `demo-log` — собственная команда тренажёра, а не обычная команда Linux. Обычные программы вроде vim/top/bash/curl не запускаются. Кавычки и некоторые совмещённые короткие флаги поддерживаются; составные shell-команды, перенаправления, переменные и подстановки отсутствуют. Ошибочная операция откатывается целиком — это правило модели, а не гарантия реального tmux.

Другие отличия и ограничения:

- Один условный клиент, окна не связаны между разными сессиями. Вложенные сессии, конфигурация префикса, настройки/плагины и большинство команд не реализованы.
- Раскладки: even-horizontal, even-vertical, tiled; цикл модели имеет три варианта. Реальный tmux имеет дополнительные раскладки. Split делит выбранную область пополам. Минимальный размер — 12% логической ширины/высоты после разделения; фокус на границах не оборачивается. Семантика всех целей/zoom/раскладок не претендует на полную совместимость.
- Имена: 1–24 Unicode-буквы, цифры, _ или -, без пробелов. До 5 сессий, 8 окон в сессии, 8 панелей в окне, последние 60 строк вывода панели, 1000 символов строки ввода, около 1 млн символов общего текста панелей, последние 120 наблюдений.
- Новое окно получает наименьший свободный индекс. Закрытие последней панели удаляет окно, последнего окна — сессию и её подключение. Вынос единственной панели в новое окно запрещён моделью.
- Визуальные панели — HTML, не VT-эмулятор. Нет escape-последовательностей, настоящего курсора программы, shell history, текстового редактора и жизненного цикла процессов.

## Сохранение

localStorage под ключом `tmux-workshop-v1`: последний урок, завершённые занятия и отдельные состояния сессий/окон/панелей, дерева, ввода, истории и текущего режима. Очистка данных браузера удаляет прогресс; аккаунтов, облака и экспорта нет. Используйте одну активную вкладку: последняя запись может заменить предыдущую. Смена порта/браузера создаёт другое сохранение.

При отказе/переполнении хранилища сайт продолжает работать в памяти и показывает предупреждение. Повреждённая/несовместимая запись не перезаписывается. Для ручного восстановления сначала сохраните исходное значение, затем удалите только ключ `tmux-workshop-v1` средствами браузера.

## Устройство и проверки

- `engine.js`: TmuxModel с `key()`, `submit()`, `command()`, `setInput()`, `snapshot()` и `TmuxModel.restore()`. Дерево панелей используется и для геометрии/фокуса, и для DOM.
- `lessons.js`: материалы, создание среды, решения/альтернативы и `check(урок,состояние) → [{label,pass}]`. UI не исполняет решения автоматически.
- `app.js`: ввод, экранные клавиши, отображение, проверка и сохранение. Строки вставляются через textContent, HTML из ввода не исполняется. CSP запрещает внешние подключения.

Из папки проекта:

```bash
node --check engine.js
node --check lessons.js
node --check app.js
node tests/engine.test.cjs
```

`tests/browser-checks.js` — async-функция для существующего Playwright page, создаёт изолированные contexts, проходит 19 занятий и проверяет UI. Нужен работающий сервер на 8769. Внешние пакеты тестирования в проект не устанавливались. Результат — `tests/browser-results.json`, подробности — [проверки.md](проверки.md).

Поведение команд сверено по [руководству tmux](https://github.com/tmux/tmux/wiki/Getting-Started) и [справочнику tmux(1)](https://man.openbsd.org/tmux.1). Авторские упражнения и интерфейс не являются официальным продуктом tmux. Оболочка адаптирована из локальной Vim-мастерской, исходный проект не менялся. Реальный tmux в среде недоступен, сравнение с запущенным tmux не проводилось; программы ради этого не устанавливались.

Проверен Chromium. Firefox/Safari, физические телефоны, реальные IME, скринридер, несколько активных вкладок и эффективность обучения не проверялись. Сайт не публиковался.
