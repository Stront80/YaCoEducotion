# Дизайн tmux-мастерской
Дата: 2026-11-26, TASK-104. Последовательная роль дизайнера.

Светлая оболочка с насыщенным бирюзовым #146a72, графитовый терминал #14262e, зелёная строка статуса, янтарный сигнал активного префикса. Собственный знак «[t]», без официального логотипа. Системные шрифты и моноширинный; текст в rem: основной 16px, регулярные подписи/клавиши от 14px, вторичные данные от 12px.

Слева программа курса, справа карточка урока. Теория/задание/подсказка/разбор рядом с рабочей областью. Практика: статус «Подключено/внешняя оболочка», вкладки окон, вложенные панели с именами %ID и выделением активной, строка статуса с именем сессии и звёздочкой текущего окна. Ниже одно подписанное поле ввода: обычная оболочка или приглашение tmux/переименования. Видимые префикс, режим, обратная связь и фокус. Сессии/окна/панели продублированы компактным деревом.

Экранные Ctrl+B, %, двойная кавычка, c/n/p/o/z/Space/d/s/!/[/x/?/:, направления и цифры выполняют те же действия, что клавиши. Подсказка: Ctrl+B отпустить, затем следующая клавиша. Нет глобального перехвата; Tab выводит фокус, Esc отменяет префикс/режим, поля вне терминала обычные. Удаление учебной панели по x запрашивает y/n внутри симулятора. Кнопка сброса подтверждается отдельно.

На телефоне меню свёрнуто, вкладки «Урок», «Терминал», «Структура». Логическая геометрия панелей сохраняется; рабочая область имеет минимальную внутреннюю ширину, маленький экран может прокручивать её внутри, вся страница не переполняется. Задания, проверка и переходы остаются доступны. Памятка сворачивается. Выбор сессии/справка/история показаны внутри терминала с понятным выходом.

Результат проверки — aria-live, кнопки/поля подписаны, фокус виден, цвет дополняется словами и значками. Установок, внешних шрифтов и изображений не нужно. Скринридер/физические мобильные клавиатуры не считать проверенными без фактического теста.
