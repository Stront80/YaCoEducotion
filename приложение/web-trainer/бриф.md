# Веб-мастерская — бриф
Дата: 2026-11-26. DEC-041. Основание: ответы пользователя и «выполняйте» после плана.

Русскоязычный локальный тренажёр для новичков: 18 уроков (6 HTML, 6 CSS, 6 JS) и проект списка задач. Цикл: теория → код → запуск → проверка результата → объяснение. Все уроки открыты, черновики и прогресс сохраняются в браузере. Просмотр решения не засчитывает урок автоматически.

Критерии: каждый урок содержит цель, теорию, задание, подсказку, старт, решение и проверку с обратной связью; работоспособные запуск/проверка/сброс/навигация; сохранение после перезагрузки, понятный отказ хранилища; адаптивность и клавиатурное управление. Итоговый проект: добавление, отметка и удаление задач. Проверки оценивают наблюдаемое поведение, не совпадение исходного текста.

Без аккаунтов, сервера приложения, сборки, зависимостей и публикации. Локальный HTTP-сервер только на 127.0.0.1. Никаких внешних шрифтов, аналитики и CDN. Не предназначен для запуска недоверенного кода из интернета. Сроки и бюджет не назначались.
