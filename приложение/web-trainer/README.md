# Веб-мастерская

Русскоязычный интерактивный тренажёр для новичков: 6 уроков HTML, 6 CSS, 6 JavaScript и итоговый список задач. Теория, редактор, результат, проверка, подсказки и разбор решения. Светлый адаптивный интерфейс, без аккаунтов и внешних библиотек.

## Запуск

Установка зависимостей не нужна. Из этой папки выполните:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте **http://127.0.0.1:8765/**. Остановка сервера — Ctrl+C. Если порт занят, выберите другой, например 8766. Прогресс привязан к браузеру и адресу, включая порт: при смене порта будет отдельное сохранение. Открытие через file:// не является поддерживаемым режимом.

Из корня рабочего пространства:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory приложение/web-trainer
```

## Как учиться

1. Выберите любой урок в программе.
2. Прочитайте объяснение и задание. Выберите HTML, CSS или JS и измените код.
3. Нажмите «Запустить», чтобы увидеть страницу, затем «Проверить», чтобы проверить условия.
4. При необходимости раскройте подсказку или разбор решения. Перенос решения и восстановление старта заменяют черновик после подтверждения.
5. Продолжайте следующий урок. На телефоне переключайте области «Задание», «Код» и «Результат».

В редакторе Tab переводит фокус к следующему элементу, отступы вводятся пробелами. Вкладки переключаются стрелками, Home и End. Код из вкладки HTML отвечает за структуру; исполняемый JavaScript вводите отдельно во вкладке JS. Обработчики onclick в HTML и встроенные script удаляются перед запуском. Локальное изображение `hello.svg` доступно в учебном HTML.

Прогресс, последний урок и черновики сохраняются в localStorage под ключом `web-workshop-v1`. Просмотр/перенос решения не засчитывает урок. Выполненные уроки остаются отмеченными после последующих экспериментов с кодом. При отказе хранилища сайт продолжает работать в памяти и показывает предупреждение. Для повреждённых/неподдерживаемых данных исходная запись сохраняется без перезаписи.

## Устройство

- `lessons.js`: материалы и проверки, постоянные ID; каждый урок содержит старт, решение и массив проверяемых условий.
- `app.js`: интерфейс, навигация и сохранение.
- `runner.js`: сборка sandbox iframe и проверка сообщений текущего запуска.
- `style.css`: оформление и адаптивность; `assets/`: локальные материалы.
- `tests/`: структурная проверка Node и сценарий для существующего Playwright; `screenshots/`: просмотренные снимки.

Sandbox не имеет `allow-same-origin`: учебный код не может читать DOM или localStorage приложения. CSP ограничивает загрузку ресурсов и сетевые обращения; формы могут вызывать submit, но их отправка запрещена. Ссылки в области результата не переходят на другие страницы. Проверка адаптивности выполняется также при 360 и 900 px. JS-задания проверяются на нескольких входах; проект — добавлением, отметкой и удалением тестовых задач.

## Проверки

Из папки проекта:

```bash
node --check app.js
node --check runner.js
node --check lessons.js
node tests/content-checks.cjs
```

`tests/browser-checks.js` — async-функция, принимающая Playwright `page`, для уже доступного браузерного инструмента. Сервер должен работать на 8765. Сценарий меняет тестовый прогресс в этом браузере: используйте отдельный тестовый профиль. Пакеты не входят в проект и не требуются для использования сайта. Зафиксированный результат — `tests/results.json`; подробности и ограничения — [проверки.md](проверки.md).

## Ограничения

Это вводный учебный курс, без оценки произвольных программ и без защиты от намеренного обхода проверки учеником. Проверяются явно описанные элементы, стили и поведение; не каждая правильная архитектура приложения соответствует контракту упражнения. DOM-урок оценивает конечный список, способ его создания разбирается в решении.

Нельзя использовать стенд для недоверенного кода из интернета: бесконечный цикл может зависнуть вместе с вкладкой, а sandbox/CSP не являются сетевым firewall. Закройте вкладку при зависании. Тайм-аут ожидания ответа не прерывает синхронный бесконечный цикл. Долгие асинхронные сценарии не входят в задания: проверки запускаются вскоре после старта.

Данные самого списка задач не сохраняются между запусками; сохраняется его исходный код. Нет аккаунтов, облачной синхронизации, аналитики, публикации и отправки формы. Safari, Firefox, физические телефоны и программы чтения с экрана не проверялись.
